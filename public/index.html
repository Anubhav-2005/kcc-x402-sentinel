Intent binding

Protocol-valid is not the same as agent-intended.

x402 defines how a resource advertises payment requirements and how a buyer authorizes them. Sentinel adds the missing wallet-side question: does this request still match what the autonomous agent meant to buy?

01

Observe the 402.

Read the resource, amount, recipient, network, asset, scheme and timeout from the actual payment requirement.

02

Bind to intent.

Compare those terms to an explicit financial contract created before payment: merchant, resource, budget and recipient.

03

Re-check before signing.

Freeze an approval snapshot and block any recipient, amount or nonce mutation before settlement.
